Causeway Sales Reconciliation: User Manual

PIE Automation Portal · Finance · Automation 01 · daily, Sunday to Thursday · about 5 minutes

Version 1.029 Oct 2026

A. Get the files ready (before opening the portal)

  1. AFS settlement report (Excel). Download the attachment from the daily AFS email and save it. Note the file password that comes with the email; you will type it in the portal. Do not open and re-save the file.
  2. Zoho invoice export (Excel). In Zoho go to Invoices, filter by the sales date, and Export. The file is named invoice_<date>_<serial>. Upload it as it is; the portal cleans it for you.
  3. Images from the email. Save screenshots of the parts of the email that show the amounts:
    • the Cash amount (from the report / image),
    • the PIE / MSwipe amount (the PIE POS section of the same image as AFS).
    The images are for reference only: the portal shows them beside your entries so you can read the amounts. It does not read numbers from them.

B. Run the automation

  1. Open the portal (http://<portal-address>:3500) and click the Causeway Sales Reconciliation card.
  2. In Inputs › Files, drop or click to choose each file in its own box:
    • AFS settlement report: the AFS Excel, then type the password in File password. A small green tick, Total matches, confirms the transactions add up to the file's Total row; if it shows red, the file is wrong and Run stays disabled.
    • Zoho invoice export: the Zoho Excel.
    • Images (for reference): the email screenshots (you can add more than one). Click a file to see it in Preview.
  3. In Manual entries, fill in Sales date, Cash amount (BHD), Cash deposit date (same day or later; shown on Receipt (Cash)) and PIE / MSwipe amount (BHD), reading the amounts from the images. Use 3 decimals, e.g. 100.500. AFS rows dated after the sales date are listed in a popup and fill AFS amount for the next day (left out of the Variance, kept in Receipt (AFS)). Put yesterday's AFS for this date in AFS amount from the previous day. Changing a filled value warns you; running is then your responsibility.
  4. Click Run automation. Check the values in Are these values correct? and press Yes, run (or Go back and edit).

C. Check the result and post to PACT

  1. Read the three figures at the top: Zoho total, Cash + AFS + PIE and Variance (Zoho total minus the payments). Read every warning before posting:
    WarningWhat to do
    AFS file dated a different dayWrong AFS report uploaded: get the report for the sales date and run again.
    Payments are more than the Zoho totalVariance is negative: re-check Cash and PIE against the images, and the Zoho date filter.
    AFS commission does not match the fileCompare the commission with the AFS Excel before posting the AFS receipt.
  2. Open the Result tabs and type the values into PACT in this order:
    #Result tabPACT document
    1Direct Sales InvoiceFinance › Direct Sales Invoice (product codes and quantities)
    2Credit Note EVD + KFC / Credit Note (JV)Credit Note (JV Type) for EVD + KFC (only shown when the day has them)
    3Receipt (Cash)Cash Receipt
    4Receipt (AFS)Bank Receipt, AFS (2.2% commission line included)
    5Receipt (PIE)Bank Receipt, MSwipe (1.65% QR charges line included)
    6Reconciliation › VarianceCredit Note (JV Type), Batelco marketing fund
  3. Download the outputs with the download buttons: causeway_reconciliation_YYYYMMDD.xlsx (every result table) and the Zoho file with a new Formatted sheet (the original sheet is unchanged).
  4. Every run is saved for audit. Open the History tab to see past runs, their inputs and outputs.
Good to know: the portal never changes your uploaded files. If you refresh the page, choose Keep my data to continue, but type the AFS password again, because passwords are never saved. If a run fails, read the message, correct the file or the value, and run again.
